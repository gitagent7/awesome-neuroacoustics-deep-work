# Contributing

Thank you for helping keep this reading list accurate.

This repository is a **reading list**: peer-reviewed papers on binaural beats, brain rhythms, noise, and sleep sound, each with a note on what the study did and did not test. It contains no audio engine and does not accept engine contributions.

---

## Standards

1. **Evidence first.** Any statement about brainwave entrainment, auditory steady-state responses, or sleep slow waves needs a peer-reviewed citation.
2. **Say what the paper tested.** Describe the stimulus (sound, light, electrical, feedback), the subjects (people, mice), and the limits. Do not stretch a result to a different stimulus.
3. **No pseudoscience.** No "manifestation frequencies", cures, or mysticism.
4. **Safety.** Mention contraindications when relevant (for example seizure disorders).
5. **Be kind.** Treat everyone with respect.

---

## What to contribute

### Corrections (most welcome)

* A note that goes beyond its paper.
* A wrong DOI, title, author list, or page range.
* A newer paper that corrects or replaces an entry.

Open an [issue](../../issues) with the entry, what is wrong, and a link to the source. A pull request is fine too.

### New papers

A paper is eligible if it is:

* published in a recognized peer-reviewed journal, or an accredited university or institute report, and
* relevant to binaural beats, brain rhythms (alpha, gamma, sensorimotor, delta), background noise, or sleep sound.

Use this format:

```markdown
* Author, A. A., & Author, B. B. (Year). *Title of the study.* Journal Name, Volume(Issue), Pages. [doi:...](https://doi.org/...)
  *One sentence: what the study did. One sentence: what it did not test.*
```

Check the DOI resolves before you submit.

### Listening guidance

Short, sourced notes on listening setup and safe volume are welcome. Cite a source for any number.

---

## How to submit (no command line needed)

1. Open `README.md` on GitHub and click the pencil icon (Edit).
2. Make your change and choose **Create a new branch and start a pull request**.
3. In the description, link the source you checked.

---

## Out of scope

* Audio, video, or tooling for generating sounds. The sessions are made with SYNAPSE OS, which is proprietary and not part of this repository.
* Promotional links, other than the channel and playlists already listed.
* Medical claims about any session.

---

## Security

* Never include keys, passwords, or private files in an issue or pull request.
* To report a security concern, use the **Security** tab on GitHub.
